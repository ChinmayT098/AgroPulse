# Agricultural Data Analysis and Crop Yield Prediction
> **Big Data Mini Project (College Viva & Demonstration Ready)**

---

## 1. Project Objective
Agriculture plays a vital role in food security and economic growth. However, crop yields are heavily influenced by complex and variable factors including rainfall, temperature fluctuations, soil texture, pH balance, and macronutrient availability (Nitrogen, Phosphorus, Potassium).

The objective of this project is to:
1. **Analyze multi-dimensional agricultural data** to uncover key factors influencing crop productivity.
2. **Train and deploy a Machine Learning model** (Random Forest Regressor) to predict crop yields accurately based on climate and soil characteristics.
3. **Demonstrate Big Data ETL processing** using PySpark for data ingestion, cleaning, transformation, and multi-level aggregation.
4. **Provide an interactive, responsive web dashboard** using Flask and Chart.js for real-time visualization and decision support.

## 4. Website Features & Pages

### A. Dashboard (`/`)
- **Dynamic KPI Cards:** Total records (1,200), Crop varieties (10), Mean crop yield, Average rainfall, and Model R² accuracy.
- **Crop-wise Yield Comparison Chart:** Interactive bar chart ranking crop productivity (Tons / Hectare).
- **Rainfall vs. Yield Scatter Plot:** Illustrating precipitation correlation with crop output.
- **Historical Productivity Trend:** 10-year trajectory (2014–2024).
- **Soil Distribution Chart:** Doughnut chart detailing soil texture types.

### B. Agricultural Data Analysis (`/analysis`)
- **Descriptive Statistics:** Full statistical breakdown (`mean`, `std`, `min`, `25%`, `50%`, `75%`, `max`).
- **Data Quality Audit:** 100% clean check verifying 0 missing values.
- **Correlation Analysis:** Pearson correlation coefficient ($r$) comparing each feature against yield.
- **Random Forest Feature Importance:** Relative weight contribution of each agricultural attribute.
- **Dataset Table Preview:** Browsable table of observations.

### C. Crop Yield Prediction (`/predict`)
- **Interactive Input Form:** Select Crop, State, Season, Soil Type, Area, Rainfall, Temperature, pH, and N-P-K nutrients.
- **Quick Preset Buttons:** 1-click loading for Rice, Wheat, and Sugarcane demo scenarios.
- **Genuine ML Prediction:** Computes yield in **Tons / Hectare** and total harvest in **Tons**.
- **Historical Comparison:** Automatically categorizes performance (*Above Average*, *Typical*, or *Below Average*).
- **Evaluation Metrics Display:** Test $R^2$ Score (99.23%) and Mean Absolute Error (MAE = 0.54 t/ha).

### D. Big Data Processing (`/spark`)
- **PySpark Architecture:** Implements standard distributed ETL:
  1. `SparkSession` Ingestion.
  2. Outlier and null filtering.
  3. `withColumn` schema transformations.
  4. `groupBy('Crop')` and `groupBy('State')` aggregations.
- **Resilient Dual-Mode Execution:** Runs on PySpark if Java JVM is available; automatically uses identical high-performance pipeline simulation if running on Windows without Java.
- **Source Code Inspector:** Embedded syntax-highlighted code viewer for viva explanation.

## 6. Viva & Examination Q&A Guide

**Q1: Why did you choose Random Forest Regressor for Crop Yield Prediction?**
> *Answer:* Random Forest is an ensemble learning method combining multiple decision trees. Agricultural productivity involves complex, non-linear interactions (e.g., rainfall helps up to an optimum, but excessive water causes waterlogging). Random Forest handles non-linearities, resists overfitting, requires minimal feature scaling, and provides direct feature importance scores.

**Q2: What is the significance of the $R^2$ Score and MAE?**
> *Answer:* 
> - **$R^2$ (Coefficient of Determination):** Measures the proportion of variance in crop yield explained by the input features. An $R^2$ of ~0.99 indicates the model captures 99% of variance.
> - **MAE (Mean Absolute Error):** Measures the average magnitude of prediction errors in the original units (Tons/Hectare). An MAE of 0.54 means our predictions deviate by only ~0.54 tons/ha on average.

**Q3: How is Big Data PySpark relevant here?**
> *Answer:* Real agricultural datasets from satellite observations, IoT soil sensors, and government mandi surveys span millions of records across multiple seasons and regions. PySpark uses distributed in-memory computing (RDDs and DataFrames) to execute cleaning, filtering, and aggregations across cluster nodes in parallel.

**Q4: How does the system handle missing or out-of-range inputs?**
> *Answer:* The backend enforces strict numerical casting, non-negative range constraints, and Scikit-Learn `ColumnTransformer` handles unknown categorical values via `handle_unknown='ignore'`.
